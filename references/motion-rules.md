# 动效规矩（数字版）

来源：`research/bench_craft.md`（Material 3 / Carbon / Apple HIG / HyperFrames 实测 / ITU-R BT.1359 / Netflix 简中字幕规范）。引擎已经按这些默认值实现，写新场景时照着用。

## 缓动

| 用途 | GSAP | cubic-bezier |
|---|---|---|
| 主体入场、标题落地（默认） | `expo.out` | (0.16, 1, 0.3, 1) |
| 卡片、图片入场 | `power4.out` | (0.22, 1, 0.36, 1) |
| 安静、长距离 | `power3.out` | (0.25, 1, 0.5, 1) |
| 退场 | `power2.in` | (0.32, 0, 0.67, 0) |
| 穿越、甩出 | `power3.in` | (0.5, 0, 0.75, 0) |
| 镜头推拉、颜色泛洪 | `power2.inOut` | (0.65, 0, 0.35, 1) |
| 描线、柱子生长 | `sine.inOut` | (0.37, 0, 0.63, 1) |
| 小徽章弹出 | `back.out(1.4)` | 过冲约 7% |
| 命中 | `tl.set`（0 ms） | — |

透明度和颜色永远不回弹；只有位置和尺寸可以弹。**"所有东西都 power2.out 0.5 秒淡入上滑"是 AI 味的来源。**

## 时长与错峰

- 单字 / 单词 0.13–0.35 s；卡片 0.55 s；行遮罩 0.7 s；镜头 0.9 s；数字滚动 1.2–1.6 s；退场 = 入场 × 0.5–0.6。
- 距离修正：`dur = 0.3 + 0.35 × √(位移px / 1920)`。
- 错峰：逐字 1 帧（≤12 字）；逐词 0.07–0.1 s；行 0.1 s；列表 0.06 s；总展开 ≤ 0.6 s。
- 下一个元素在上一个完成 30–50% 时出发。

## 对口播

```
入场开始 = 词起点 − p90(缓动) × 时长 − 2 帧      p90: expo.out .33 | power4.out .37 | power3.out .44 | power2.out .54
硬切 / 命中 = 词起点 − 0…2 帧，用 tl.set
反应（柴犬点头）= 词起点 + 0…1 帧
画面早于声音 ≤125 ms 察觉不到；晚于声音 >45 ms 会被察觉
```
在 video.json 里写 `"@词"` 就自动按这个公式算。

## 读时

- 口播没念的字（标签、来源）：`max(1.0, 0.5 + 字数/6)` 秒。
- 字幕：≤ 9 字/秒，≤ 16 字/行，最短 0.8 s，入点提前 2 帧，出点延后 5 帧，间隔 <0.3 s 就桥接（不闪）。
- 动效标题每屏 4–12 字；超出就分屏，不缩字号。

## 剪辑

- 同一章节内**硬切为主**（或速度匹配的 slide / zoom：旧画面 power4.in 加速离场，新画面同方向 power4.out 减速入场，接缝共用 10–12px 模糊）。
- 章节之间用风格的**招牌转场**，一部片 2–3 种以内，每种都要有理由。
- 不交叉溶解两个不相干的世界（`film` 风格的黑场除外）。

## 禁止

- 标题、UI 上的呼吸、漂浮、脉冲循环；标题落地后还在滑；场景末尾慢推；`repeat:-1`。
- 一页里高亮好几个词；字体超过 2 族；强调色超过 1 个。
- 屏幕大字和字幕同时显示同一整句。
- 图表或证据一闪而过（< 4 秒）。
- 暗底上的全屏线性渐变（H.264 会出色带，用径向渐变）；5% 以下透明度的颗粒（压缩后消失，用 6–12%）。
