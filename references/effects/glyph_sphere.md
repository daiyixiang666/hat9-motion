# `glyph_sphere` · 代码球成字

<img src="../../assets/previews/fx/glyph_sphere.webp" width="480" alt="glyph_sphere 横屏"> <img src="../../assets/previews/fx/glyph_sphere_v.webp" width="160" alt="glyph_sphere 竖屏">

**怎么动**：约 1,200 个等宽字符（0–9、A–F、{}[]<>/=+，18–34 px）排成一个大球（竖屏直径 860 px、中心 y 760；横屏直径为画面高度的 70%），带 12° 倾角绕竖轴慢转（每秒 24°），近大远小、背面更暗，球心一团强调色的光。到关键时刻，所有字符按离中心的远近先后飞出（0.9 秒，expo.inOut），落进数字或词的真实字形里（构建时用风格的标题字体栅格化），拼成大字；字块约 900 px 宽、字高 ≥ 200 px；随后 6 帧内实心字淡入盖上，清楚可读，标题落在它上方、说明行在下方。另外约四分之一的字符变成一圈淡淡的倾斜光环，绕着数字继续转。

| 项 | 内容 |
|---|---|
| 类别 | 数据 |
| 适合的句子 | 一个要郑重揭晓的数字或词：「全年营收 169.9 亿」，科技、数据、AI 话题 |
| 建议时长 | 4.5–5.5 秒 |
| 参数 | `value`（必填，数字或短词）、`label`（上方小标题）、`sub`（数字下方一行）、`at`（字符起飞的时刻，`"@词"` 或拍内秒数，默认拍长的 45%） |
| 横屏 / 竖屏 | ✓ / ✓（竖屏球半径 360 px，字块按内容框宽度排满；横屏球半径 300 px） |
| 跟风格换皮 | 字符和实心字用 --fg，球心光用 --accent，标题字体用风格的 display（细笔画字体自动改用粗黑体取字形）；没写 `theme` 时画在风格自己的底色上 |
| 什么时候用 | 一个数字本身就是这一拍的全部重点 |
| 什么时候不用 | 要同时讲清好几个数；很长的词（> 8 个字） |
| 同步口播 | `at` 可以对准说到数字的那一刻；落定后镜头缓慢推近 |
| 缺内容 | 没写 `value` 会直接报错（不会画空骨架）；确实要骨架时写 `"skeleton": true` |
| 接转场 | 实心数字带 `data-anchor="value"`，下一拍写 `"tr": "anchor_match"` 时它会被带过去 |

```json
{
 "scene": "fx",
 "fx": "glyph_sphere",
 "value": "169.9 亿",
 "label": "名创优品 · 2024 全年营收",
 "sub": "同比 +22.8%",
 "line": "2024 年，名创优品全年营收 *169.9 亿*。",
 "src": "名创优品 2024 年度业绩公告（港交所 9896）",
 "t": "@关键词"
}
```

**已知坑**：很短的值（2–3 个字）字块会比较窄；细笔画字体会改用粗黑体取字形。

**实现**：`scripts/h9/fx/fx3_scene.py`。
