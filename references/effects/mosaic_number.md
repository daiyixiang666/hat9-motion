# `mosaic_number` · 作品拼数字 · Mosaic Number

<img src="../../assets/previews/fx/mosaic_number.webp" width="480" alt="mosaic_number 横屏"> <img src="../../assets/previews/fx/mosaic_number_v.webp" width="160" alt="mosaic_number 竖屏">

**怎么动**：上千张真实缩略图铺满画面、近景开场，计数器边跳边拉远镜头；拉到底后，落在数字字形之外的格子熄灭，字形里的格子留亮，强调色描出数字轮廓，副标题落在下面——数字就是用作品拼出来的。

**什么时候用**：「收录了 300 张示例」「覆盖 18 种风格」「服务过 2.6 万人」这类**数量即证据**的句子，手上又有真实作品图时。

| 项 | 内容 |
|---|---|
| 类别 | 数字变形状 |
| 建议时长 | 5–6 秒（拉远 2.4 秒 + 揭示 + 停留） |
| 横屏 / 竖屏 | ✓ / ✓ |

**参数**

| 参数 | 说明 |
|---|---|
| `items / images / folder` | 作品图或视频（1–400 张，自动循环铺满 1000–2600 格，相邻不重复；视频取一帧） |
| `value` | 计数器停在的数 |
| `text` | 字形里画的数字，如 "174"（默认 = value） |
| `sub` | 数字下面的说明 |
| `from` | 计数起点，默认 0 |
| `tiles` | 格子上限（渲染时间） |
| `tile_ar` | 格子宽高比，默认 0.8 |
| `zoom` | 开场近景倍数，默认 3.2 |
| `subject / subject_label` | 揭示后落下的主体小卡（可选） |
| `mock` | 示意标签 |

```json
{
 "scene": "fx",
 "fx": "mosaic_number",
 "folder": "../media/assets/frames",
 "value": 300,
 "text": "300",
 "sub": "张示例静帧 · 全部由九帽动效生成",
 "line": "这 *300 张* 画面，全是九帽自己做出来的。",
 "t": "@关键词"
}
```

所有这一组效果（数字变形状）：颜色、字体、圆角、描边、阴影、入场缓动都取自当前风格（26 种风格自动换皮）；横竖屏同一套参数；可选 `subject`（图片或视频）把主讲人放在旁边的小卡里。

**已知坑**：字符越多每笔越细：超过 5 个字符改用更短的写法（"2.6万"）。格子是一张图集，几千格也很快；字形用风格的数字字体排，衬线体笔画细，格子会自动变小。
