# `ui_lift` · 真实组件出框

**怎么动**：真实网页装在浏览器框里，先滚到某个组件，框出来、其余变暗；然后这个组件自己的 2 倍高清截图从页面里「拎」出来，放大到画面中间，页面退到后面虚化；光标再去点它真实的按钮，每个标签都是按钮上原本的字。所有画面都是真实截图，不重画界面。

| 项 | 内容 |
|---|---|
| 类别 | 屏幕 |
| 适合的句子 | 「就是这个按钮」「它的价格表长这样」「首页最上面这一块」——讲产品 / 工具时指着真实界面说 |
| 建议时长 | 4–6 秒（出框约在 1.9 秒，之后每个点击 0.7 秒以上） |
| 参数 | `image`（整页截图）、`box`（组件在整页上的位置，像素或 0–1）、`piece`（组件自己的截图，不给就从整页裁）、`path`（0–6 步，`act`: click / hover，坐标相对组件截图）、`frame`、`url`、`tab`、`lift_at`、`dark_chrome` |
| 横屏 / 竖屏 | ✓ / ✓（竖屏：页面按竖窗口裁在组件周围、不缩成一小条；组件出框后占画面宽约 92%，慢推近；标签 36px） |
| 跟风格换皮 | 框线、点击波纹、标签用风格强调色，底色跟风格走 |

素材用 `scripts/ui_capture.py` 抓（竖屏片加 `--aspect 9:16`，抓手机版页面，字在手机上才读得清）：它会给出整页图、每个组件的截图、`ui.json`（位置、可点的按钮）和现成的 beat。

```json
{
 "scene": "fx",
 "fx": "ui_lift",
 "theme": "paper",
 "topic": "真实界面",
 "image": "assets/repo/repo-page.jpg",
 "box": [68, 7358, 646, 554],
 "piece": "assets/repo/repo-04-card.png",
 "url": "github.com/daiyixiang666/hat9-motion",
 "frame": "browser",
 "path": [
  {"act": "hover", "x": 0.5, "y": 0.5, "label": "《一杯 4 块钱的柠檬水》"}
 ],
 "line": "README 里的成片示例，*整块拎出来*给你看。",
 "t": "@关键词"
}
```

**已知坑**：竖屏里太高的组件（高 > 宽）出框后占不满宽度，ui_capture 会优先挑横向的组件；`box` 用整页图的像素（`ui.json` 里的 `box_px`），`path` 用组件截图的像素（`ui.json` 里 `hot` 的中心）；静态截图点了不会变，要演示变化请用录屏（`screencast`）。
