# `dolly_layers` · 推轨穿层

<img src="../../assets/previews/fx/dolly_layers.webp" width="480" alt="dolly_layers 横屏"> <img src="../../assets/previews/fx/dolly_layers_v.webp" width="160" alt="dolly_layers 竖屏">

**怎么动**：镜头一路往前推，穿过 4–6 层真实纵深的平面：标题、每个要点、最后的数字。在焦平面附近的那层完全清晰、内容占画面宽 70% 以上，前方的层小而虚，穿过镜头的层扫过并散掉；每层在口播说到它时到焦。

| 项 | 内容 |
|---|---|
| 类别 | 镜头 |
| 适合的句子 | 「工厂、仓配、采购，背后是……」逐层递进、最后落到一个数 |
| 建议时长 | 5 秒左右（每层 ≥ 0.8 秒） |
| 参数 | `title` `items`（2–4）`value`（都必填，合计 4–6 层）、`unit`、`label`（数字下的小字） |
| 横屏 / 竖屏 | ✓ / ✓（竖屏：每层文字在字幕带上方，透视地面网格铺到底边；横屏同理） |
| 跟风格换皮 | 颜色只用风格的 token（--bg --fg --muted --accent --card --card-fg），字体用风格的 display / body / num；没写 `theme` 时画在风格自己的底色上 |
| 什么时候用 | 递进、深入、「一层层剥开」 |
| 什么时候不用 | 要点之间要并排比较（看不到同时出现）；要点很多（> 4） |
| 同步口播 | 有字级时间戳（meta.words）时，条目 / 关键时刻落在说到它的那一刻；`at` 可以写 `"@词"` 或拍内秒数 |
| 缺内容 | 必填参数缺了会直接报错（不会画空骨架）；确实要骨架时写 `"skeleton": true` |

```json
{
 "scene": "fx",
 "fx": "dolly_layers",
 "topic": "商业拆解",
 "title": "4 块钱的三个底气",
 "items": [
  "自有工厂",
  "自建仓配",
  "规模采购"
 ],
 "value": "46,479",
 "unit": "家店",
 "label": "一起下单 · 截至 2024 年底",
 "line": "工厂、仓配、采购，背后是 *4.6 万家店* 一起下单。",
 "src": "蜜雪集团招股书 · 2024 年度业绩公告",
 "t": "@关键词"
}
```

**已知坑**：三维用 CSS perspective；每帧按距离焦平面计算模糊，跟时间轴同步可任意跳帧。
