# `montage` · 卡拍快切

**怎么动**：口播停顿处，一串真实画面（成片、素材、录屏）每一刀落在配乐的节拍上（一拍或半拍）。每段自动挑最好看的那一秒：画面完整、读得清、里面没有转场或硬切，略有动作；每刀开头轻推近一下，顶部一块实色标签（≤ 8 个字），不压字幕。这一段配乐自动推上来。

| 项 | 内容 |
|---|---|
| 类别 | 节奏 |
| 适合的句子 | 「画面基本都有」「同一条文案，完全不同的样子」——说完一句、停一下，把一批画面啪啪啪秀出来 |
| 建议时长 | 3–8 刀，一刀一拍（约 0.5 秒）或半拍 |
| 参数 | `clips`（每段 `src`、`in`: `"auto"` 或秒数、`label`、**`line`：这段对应哪句话，必填**）、`per`（每刀几拍，`1` 或 `0.5`）、`music`（默认推上来，`false` 关掉） |
| 横屏 / 竖屏 | ✓ / ✓（按画幅铺满裁切） |
| 卡拍 | 需要 `meta.music` 旁边有同名 `.beats.json`（或写 `meta.music_beats`）；没有节拍表时按 `bpm` 等分 |

```json
{"scene": "fx", "fx": "montage", "t": "@走得越多$", "per": 1, "clips": [
  {"src": "assets/clips/factory.mp4", "in": "auto", "label": "工厂", "line": "原料走得越多"},
  {"src": "assets/clips/ship.mp4", "in": "auto", "label": "海运", "line": "原料走得越多"}
]}
```

渲染完已经做好的片子，也可以用 `hat9.py montage montage.json --into 成片.mp4` 把一段快切叠进去。完整示例：`examples/beatsync/`。
