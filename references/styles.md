# 风格

风格管「整条片子长什么样」：底色、字体、质感层、字幕皮肤、柴犬出场方式。效果（`scenes/fx` + `scripts/h9/aefx.py`）管「每一句怎么动」，可以在任何风格里用。

| id | 名称 | 适合 | 说明 |
|---|---|---|---|
| `press` | 财经刊 | 商业拆解、数据口播、"谁在赚钱" | 暖白纸底 + 墨黑大字 + 信号红 + 柠檬黄色块（Businessweek / FT 图表 / 小Lin说）；每页固定页眉页脚（栏目、章节号、数据来源）；8 个自带场景：价格对利润、点阵对比、色块反转、收入构成 + 推进到小数、钱货两条线、飞轮、判断句、落版；每页有镜头调度；横竖屏各自排版。示例 `examples/mixue/` |
| `reel` | 动效库默认 | 大多数口播、快节奏短视频 | 暖黑底 + 一个橙色强调，干净中性，给 40 个 AE 动效当舞台（默认） |
| `hud` | 暗场 HUD | 拆解、排序、"到底差在哪" | 对标所长林超 / 小Lin说：编号胶囊栈、票据双线数字卡、取景框四角 |
| `studio` | 三维影棚（金属） | 开场、产品、需要"贵"的一期 | Three.js 实时三维：立体中文字、PBR 材质、景深、辉光，镜头在一个连续布景里飞行 |
| `clay` | 陶土影棚 | 观点、审美、要温度又要高级 | 同一个三维引擎的哑光陶土版：赤陶强调、柔和真实投影、三维宋体立体字 |

`styles/legacy/` 里是 0.1 版的 10 个风格（社论、证据桌、胶片、暗场纪录……），用户评价"彼此太像、手法很套"，保留作参考，不再默认加载。

## 新增风格

数据 / 商业类先看 `styles/press.py`（整套自写场景 + `shots()` 镜头调度的写法）；只换皮的话复制 `styles/reel.py`，改 `tokens`（颜色）、`fonts`（只用 `assets/fonts.json` 里的字体）、`layers`（质感层）、`sfx`。需要整片一体的布景（比如三维、书页）就写一个 `WORLD()`（参考 `styles/studio.py`）。改完跑：

```bash
python3 scripts/hat9.py render examples/demo/video.json --style 新id --preview
```

先排 2–3 张静帧和标杆并排对比（`scripts/board.py`），过关再做动画。**不能只换底色就叫新风格。**
