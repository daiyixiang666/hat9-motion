# 手艺规矩：别让片子一看就是 AI 默认款

给做片的 AI 和人看的硬规矩。改编自 OpenDesign（Apache-2.0）的 `craft/anti-ai-slop.md`、`craft/animation-discipline.md`、`craft/typography.md`，以及它的 HyperFrames 模板 `house-style.md`、`data-in-motion.md`、`references/motion-principles.md`、`references/typography.md`；其中 anti-ai-slop 和 typography 又源自 refero_skill（MIT）。原文面向网页，这里按 1080p 口播视频重写。

能自动查的部分已经写进 `scripts/craft_lint.py`（规则名写在括号里）：

```bash
python3 scripts/craft_lint.py examples/mixue/build/press_16x9      # 查一个构建
python3 scripts/render.py work/video.json --styles press --lint     # 渲染时顺带查（只报告，不拦）
```

P0 必须改，P1 应该改，P2 值得看一眼。

## 一、AI 默认款黑名单

| 等级 | 手法 | 为什么 | 怎么改 |
|---|---|---|---|
| P0 | Tailwind 默认靛紫当强调色 `#6366f1` `#4f46e5` `#8b5cf6` `#7c3aed` `#a855f7` …（indigo-accent） | 最典型的 AI 标志色 | 用风格自己的强调色 |
| P0 | 两色"信任"渐变：紫→蓝、蓝→青、靛→粉（trust-gradient） | 模板感最重 | 纯色面 + 有意图的字 |
| P0 | 占位文案：lorem ipsum、示例文字（filler-copy） | 空就是空，不要编 | 用真实内容，或改构图 |
| P1 | 编造的数字："快 10 倍""99.9%""提升 300%"，没有出处（unsourced-metric） | 观众一眼不信 | 印出处，或在画面上标「示意」 |
| P1 | emoji 当图标 ✨🚀🎯⚡🔥💡（emoji-icon） | 廉价 | 线性 SVG 图标，描边 1.6–1.8px，`currentColor` |
| P1 | 圆角卡片 + 彩色左边条（left-border-card） | "AI 仪表盘卡片"的标准形状 | 去掉圆角或去掉左边条 |
| P1 | 渐变字（gradient-text） | 常见默认手法 | 只在内容需要时用（比如光泽扫过效果） |
| P1 | 拉丁标题用训练数据默认字体：Inter、Roboto、Open Sans、Lato、Poppins、Playfair Display、EB Garamond、Cormorant、Syne……（banned-display-font） | 千篇一律；Syne 是最常见的"假个性"字体 | 换一款有性格的；**中文字体（思源黑体 / 宋体等）不受此限** |
| P2 | 纯 `#000` / `#fff` 作大面积底（pure-ground） | 纯黑像"没加载出来" | 往强调色方向带一点色温 |
| P2 | 一排完全一样的卡片（identical-cards） | 没有主次 | 大小、位置、颜色至少拉开一项 |

### 工作室规矩（也由 craft_lint 查）

| 等级 | 手法 | 怎么改 |
|---|---|---|
| P1 | 渐变底 + 居中一行标题（gradient-title） | 最典型的 AI 片头：换成纯色面或真实画面，标题贴边 |
| P1 / P2 | 什么都在淡入：只动透明度的入场占一半以上为 P1，三成半以上为 P2（all-fades） | 入场配方向、缩放、遮罩或擦除；淡入只留给要安静的地方 |
| P1 | 模板占位标签：「Title」「标题文字」「Your text here」，或单独一个「Step 1」「功能一」旁边没有内容（generic-label） | 写成这一屏真正的内容 |
| P1 | 字体太多：同一种文字的标题字超过 2 款，或正文黑体超过 1 款（font-count） | 一款标题字 + 一款正文字；数字、代码各可再配一款；只出现一两次的点缀不算 |
| P2 | 强调色太多：风格配色之外还有 3 种以上颜色反复出现（extra-accent） | 一条片子一个强调色，其余用风格自己的颜色 |

另外两条机器查不了，自己看静帧板：**每 2–4 秒画面上要有新东西**（`review` 会查静止过久）；**讲产品只用真实界面**，网址先过一遍 `scripts/ui_capture.py`，不要自己画一个"差不多"的界面。

规则不是禁令：庄重的收尾用居中、真实产品界面用卡片、某款"禁用"字体恰好贴题，都可以。要的是**有意为之**，不是顺手默认。

## 二、动效纪律（视频版）

**速度表达分量**

| 时长 | 感觉 | 用在 |
|---|---|---|
| 0.15–0.3 秒 | 能量、紧迫、果断 | 冲击字、卡点、小标签 |
| 0.3–0.5 秒 | 专业，适合大多数内容 | 常规入场 |
| 0.5–0.8 秒 | 分量、高级、沉思 | 大标题、关键数字 |
| 0.8–2.0 秒 | 电影感、情绪 | 开场、留白、镜头推进 |

短于 0.12 秒（约 3 帧）观众看不出在动（too-fast）；入场超过 1.2 秒要确认是有意的（slow-entrance）。同一条片子里最慢的场景应该比最快的慢 3 倍左右。

**缓动是情绪**：同一个滑入，`expo.out` 是自信，`sine.inOut` 是梦幻，`elastic.out` 是俏皮。

- 进场用 `.out`（先快后慢），离场用 `.in`（先慢后快甩出去），位置之间移动用 `.inOut`。反过来用会显得拖沓或不情愿。
- 不要所有动作都用同一种缓动、同一个时长、同一个方向（ease-monoculture）。一个场景里同一种缓动的独立动作不超过两个。
- 第一个动作晚 0.1–0.3 秒开始，零延迟像跳切（starts-at-zero）。

**每个场景三段**：搭建（0–30%）元素错开进场 → 呼吸（30–70%）内容停在画面上、只留一种环境微动 → 收束（70–100%）离场或明确的结尾。离场比进场快（0.4 秒进、0.25 秒出）。错开总长控制在 0.5 秒内，按重要程度排序，先动的最重要。

**转场就是含义**：交叉淡化 = "接着说"；硬切 = "醒醒"、语气转折；慢溶 = "跟我飘一会儿"。别什么都用淡化。

**闪烁上限**：任意 1 秒内闪烁不超过 3 次（WCAG 2.3.1），故障、闪白、频闪类效果要守住。循环动效（加载、思考）要有节制，到了就停。

## 三、构图：视频画面不是网页

- **至少两个焦点**，眼睛要有地方移动；不要一块字孤零零漂在空画面中间。
- **铺满画面**：主标题占画面宽度 60–80%，别用网页尺寸的元素。
- **至少三层**：背景处理（光晕、巨型淡字、色块）+ 前景内容 + 点缀（分隔线、标签、数据条）。
- **背景不空**：2–5 个持续存在、缓慢动着的装饰（呼吸的光晕、3–8% 透明度的巨型主题字、细线、颗粒、题材相关的几何），在元素逐个进场时画面也不空。静止的装饰是死的。
- **贴边**：内容锚定在左上或右下，居中漂浮是网页做法；用分区布局（左数据右内容、顶条元信息 + 下方通栏）。
- **结构线**：细线、分隔、边框面板能给视线铺路，而且很好动（scaleX 从 0 拉开）。
- **竖屏避开平台界面**：9:16 的字幕、来源和其他要读的字都放在顶部 200 px 以下、底部 400 px（标题 / 音乐 / 评论栏）以上、右下按钮区以外；底部 400 px 只放画面、质感、颜色和页码这类家具。`style check`、`brief check` 和 `render` 会量字幕的真实位置，`style check` 还会扫描示例片里每一处要读的字，压进去就是错误；页眉、页码这类家具可以写进风格的 `safe_exempt`。

## 四、字体

- **中文行高**：标题 1.3–1.4，正文 1.7–1.8；拉丁标题可以 1.0–1.2。中文字形占满字身框，用拉丁的 1.05 行高两行标题会撞在一起，封面大标题尤其要查。
- **中文不加负字距**：中文本来就在方格里，`-0.02em` 只会挤；负字距只给拉丁标题。中英混排时，紧凑的拉丁参数只加在拉丁元素上，别让中文继承。
- **配对**：衬线 + 无衬线，或无衬线 + 等宽；不要两款无衬线。
- **字重和字号**：标题 700–900，正文 300–400；1080p 视频里标题 60px 以上，正文和字幕 20px 以上（手机能看清的下限约 28px）。字号按 1.2 或 1.25 倍阶梯，一条片子 6–8 级以内。

## 五、颜色

- 动手前先定三个：背景、前景、一个强调色。一条片子背景统一，不要每个元素临时发明颜色。
- 中性色往强调色方向带一点冷暖，死灰不如有色温的灰。
- 按题材定明暗：食品、健康、儿童偏亮；科技、电影、财经偏暗。
- 文字对比度至少 WCAG AA（`hyperframes check` 会查）；把装饰去掉后字也必须读得清。

## 六、数据画面

- **同一个概念的连续数据**（Q1→Q4、同一产品的三个指标）留在同一个视觉空间、同一套样式，只换数值。换样式应该意味着换了话题。
- **数字要有视觉重量**：配一个比例填充条、背景色块变化、代表数值的形状或进度环，让数字"压得住"画面，而不是一行字飘着。
- **避开网页套路**：多轴图（3 秒内看不懂交点）、六宫格仪表盘（2–3 个并排就够）、网格线 / 刻度 / 图例（运动中全是噪音）、图表库原样输出（用 GSAP + SVG 自己画）。饼图难以比较，需要比例时用环形图（`donut`）且只放 1–2 个比例。

## 七、怎么加"灵魂"

大约 **80% 成熟手法 + 20% 独特选择**。那 20% 放在：

- 一个大胆的视觉动作：一种字体、一个颜色决定、一个出人意料的比例；
- 口吻：画面里的小字像懂行的人写的；
- 一处让人记住的微动效：一个数字滚上去、一下 2 帧的顿挫；
- 一个只有真用过、真懂行的人才会放的细节（真实的单位、行业术语、文件格式）。

截一帧给外人看，能认出是哪个频道、讲的什么题材，就有灵魂；认不出，就是模板。
