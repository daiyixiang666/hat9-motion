# 步骤导航 Nav 与钉住的章节标题 Pin

讲流程的片子（「我做一条视频分六步」）常见两个问题：观众看到第四步时已经忘了一共几步、现在在哪；一个清单讲完以后，后面每一段到底在讲清单里的哪一条。

- **步骤导航 `meta.nav`**：整章常驻的一排步骤，当前步骤高亮，随片子一步步往前走。
- **钉住的标题 `beat.pin`**：清单先全屏出现，之后每一条单独讲的那几拍，左上角钉着这一条的名字；上一拍就是那张清单时，标题直接从清单里**飞**到左上角。

两者都是整片的一层（和 `meta.device` 一样），不占 beat，也不改 beat 里的效果。

## JSON

```json
"meta": {
  "nav": {"steps": ["选题", "找素材", "写稿", "配音字幕", "剪辑", "封面发布"], "numbered": true}
},
"beats": [
  { "fx": "mask_up", "text": "一条片子六步", ... },                 // 没写 step：导航收起
  { "fx": "stack_build", "step": 1, ... },                          // 第 1 步亮
  { "fx": "key_card", "step": "写稿", ... },                        // 也可以写步骤名
  { "fx": "list_stack", "items": ["工作室和团队", "设备", "流程"], ... },
  { "fx": "stack_build", "pin": {"index": 1, "text": "工作室和团队"}, ... },   // 从清单里飞上去
  { "fx": "strike_fix",  "pin": {"index": 1, "text": "工作室和团队"}, ... },   // 同一个 pin：留着不动
  { "fx": "key_card",    "pin": {"index": 2, "text": "设备"}, ... }            // 换 pin：旧的向左滑走，新的滑进来
]
```

| 字段 | 意思 |
|---|---|
| `meta.nav.steps` | 2–8 个步骤名。超过 8 个会报错：请分成几章，每章不超过 8 步 |
| `meta.nav.numbered` | 默认 `true`：每个步骤前带「01」小序号 |
| beat `step` | 这一拍是第几步（从 1 数），或步骤名（写前几个字也能认出）。没写 `step` 的拍，导航滑出画面；下一个写了 `step` 的拍再滑回来 |
| beat `pin` | `{"index": 1, "text": "工作室和团队"}`，或只写字符串。相邻几拍写同一个 pin 时它一直留着 |

## 横屏 16:9

- 导航是顶部一排胶囊：y 62–130（高 68 px），从 x 110 起，间距 16 px，左右内边距 22 px，标签 34 px，前面是 26 px 的序号。当前步骤用风格的墨色填满、字用纸色；其他步骤描边、45% 透明；走过的步骤下面一条 3 px 强调色短线。
- 换步骤时，那块填色像一颗胶囊沿着这一排滑过去（10 帧，冲过头 6% 再回来），不是淡入淡出；胶囊离开之前，上一步自己的填色一直留着。
- 标签太长时先缩到 28 px，再按同一个上限加省略号；连这样也放不下（比如 8 个长标签）时，其余步骤只留序号「03」，只有当前步骤显示全名，换步骤时整排跟着重排。
- 钉住的标题：x 110、y 60–124，强调色序号 28 px + 标题 44 px / 800（放不下先缩到 32 px 再加省略号）；导航同时在时，变成跟在这一排最后一颗胶囊后面的描边标签（34 px）。

## 竖屏 9:16

- 一排放不下，改成左侧一根竖向进度轨：x 40–58、y 320–1300，线宽 4 px，每步一个 22 px 节点（当前 30 px；走过的实心、没到的空心）。只显示当前这一步的名字：顶部一枚标题胶囊（y 208–284，高 76 px，名字 42 px、序号 34 px 等宽，「03 / 06 · 写稿」，最宽到 x 960，先缩到 34 px 再加省略号）。
- 换步骤时，填色顺着轨道往下流到新节点，标题胶囊里的字像里程表一样往上翻（9 帧）。
- 导航在时，这一拍的画面以 (1000, 1600) 为基准缩到 0.95：左边让出轨道、顶部让出钉住的标题，任何东西都不会往右下按钮区挪，边缘淡出、看不到接缝。
- 轨道是家具（`data-safe="ignore"`），标题胶囊在安全区里。
- 钉住的标题：x 80、y 208 起，标题 46 px、序号 32 px（先缩到 36 px 再加省略号）；导航同时在时，放在标题胶囊正下方（y 300–360），轨道从 y 400 开始。
- 1:1、4:5、3:4 用竖屏的版面，按画幅窗口缩放。

## 和别的层一起用

- **风格的页眉**：导航或钉住的标题在画面上时，它占风格自己的页眉位置——效果外框（`.ctx`）在导航底边以上的部分让开，风格场景里的页眉行（`reel` 的话题行、`riso` 的版头、`atlas` / `iso3d` 的标题条……）暂时隐藏；导航收起后页眉回来。
- 风格可以自己声明页眉位置：风格文件里写 `"nav_slot": {"hide": ["选择器", ...], "16:9": {"y": 62}, "9:16": {"y": 208}}`。`hide` 替换默认要隐藏的页眉，`y` 改导航和钉住标题那一行的位置。
- **`meta.device`**：导航排到装置顶部外框下面；章节换底色时，导航的墨色、纸色和强调色跟着这一章的颜色世界换，强调色底的章节里也看得清。
- **`meta.presenter`**：有导航或钉住标题的拍，口播主体和图文的区域排在导航下面（横屏让出顶部约 70 px，竖屏让出标题胶囊和左边的进度轨），不会被导航压住。
- **字幕**：不受影响；导航在字幕层下面、主体和效果上面。

## 已知限制

- 竖屏缩放让这一拍里的字也缩到 0.95：贴人版式（`stack_build` `key_card` `side_stat` 等）竖屏的小标签是 30 px，缩放后约 28.5 px。
- `studio` 这类整片一个三维场景的风格里，效果自己的眉题可能离导航很近。
- 清单的那一拍和钉住标题的那一拍之间如果隔了别的拍，标题不会飞，而是滑进来。

示例：`examples/fx4/`（《一份 video.json 怎么变成成片》，导航 + 钉住的命令名 + 八个流程效果，横竖屏各排一版）。
