# 章节装置 Device：整片套在一个界面里，每章换模式名和底色

整片套进一个通用的界面外框——**相机取景器**、**浏览器窗口**或**手机屏幕**。外框整片都在；到章节交界处，模式名 / 标签页标题带一个小动画换掉，背景换成这一章的颜色世界。观众不用读也知道换章了。

参考：抖音 7701488753897917723——整片在一个相机界面里，每章换一个模式名，而且和内容对得上（TIME-LAPSE 讲每天更新、MULTI-LENS 讲多模型兼容、BURST 讲一群 agent、SELFIE 自我介绍），每章一个底色（白、蓝、黑、浅）。我们的相机是通用相机界面（取景角标、REC 时间码、模式胶囊、模式转盘、快门），不带任何真实 App 的品牌。

## JSON

```json
"meta": {
  "device": {"kind": "camera", "brand": "我的频道", "url": "example.com"}
  // 或者直接 "device": "camera" | "browser" | "phone" | "none"
},
"beats": [
  { "t": 0,          "chapter": {"label": "PANO", "sub": "全景", "bg": "ink", "title": "周活"}, ... },
  { "t": "@两年前",   "chapter": {"label": "TIME-LAPSE", "sub": "延时", "bg": "paper"}, ... },
  { "t": "@现在它",   "chapter": {"label": "BURST", "sub": "连拍", "bg": "accent"}, ... },
  { "t": "@OpenAI押", "chapter": {"label": "OpenAI 的 2030 目标", "device": "browser", "url": "example.com/notes/openai-2030"}, ... },
  { "t": "@所以别",   "chapter": {"label": "SELFIE", "sub": "自拍", "bg": "card"}, ... }
]
```

| 字段 | 意思 |
|---|---|
| `label` | 模式名（相机胶囊、转盘）/ 标签页标题（浏览器）/ 屏幕标题（手机） |
| `sub` | 本地语言的短名，和 label 一起显示（相机：「全景 PANO」，转盘里显示它） |
| `bg` | 这一章的底色：风格色名（`bg` `fg` `ink` `paper` `accent` `card` `muted`）或颜色值。不写就按风格调色板轮换，且不和上一章相同。写色名时换风格会跟着换色 |
| `title` | 角上的一行小字（相机：`// 02 — 延时 · 两年`）/ 页面标题（浏览器，优先于 label） |
| `device` | 只这一章换成别的装置（比如一章放进浏览器里讲网页来源） |
| `url` | 浏览器地址栏（每章重新打一遍） |

旧写法 `"chapter": true` 仍然表示「这里换章，用风格的招牌转场」。章节对象在装置里时，换章由装置自己完成（换标签 + 底色 + 取景框呼吸一下），不再叠全屏转场；beat 里写了 `tr` 时以 `tr` 为准。

没有装置、只有章节对象时（`device: "none"`），只换底色世界，不画外框。

## 每种装置

- **camera**：四角取景框；左上 `// 01 — 模式 · 标题` + 红点 REC 时间码（跟着片子走）；顶部居中模式胶囊；右上品牌 + 画幅帧率；9:16 底部是模式转盘（列出片中所有相机章节，当前的居中、用强调色）+ 缩略图（上一章的底色）+ 快门 + 翻转；16:9 这些竖排在右侧栏。录像类模式（REC / VIDEO / LIVE / TIME-LAPSE / SLO-MO）快门芯变成红色圆角方块。换章：胶囊和标题行上下翻换、转盘滑动、取景框轻轻收一下、一下很淡的闪光、快门声。
- **browser**：红黄绿三点、标签页（标题 = 当前章节）、地址栏（每章逐字打出 url）+ 一条加载条。
- **phone**：状态栏（时间跟着片子走、信号、电量）+ 应用标题栏（标题横滑换掉）+ 底部横条。

## 颜色世界

每章的 `bg` 会推出一整套页面颜色（前景、次要文字、线、卡片、强调色，保证对比度），写在这个 beat 的版面盒子上，所以效果画出来的底色、文字和这一章一致；装置的文字颜色也跟着底色在深浅之间切换。

## 不挡字幕

装置只占边缘：9:16 顶部 y 176–300、底部 y 1560 以下（字幕带约 1320–1500 留空）；16:9 顶部 120px 和右侧 220px（相机），字幕在底部居中。主体和图形都排在装置留出的内容框里（`device.content_box`）。

## 风格换皮

胶囊 / 标签圆角、取景角标的粗细和长度、胶囊底色、标签字体来自风格（`scripts/h9/device.py` 的 `SKIN`；风格文件里可写 `"device_skin": {...}`）：poster / zine 方角粗线、flat 全圆角厚线、screen 细线小角、ink 细线衬线标签……
